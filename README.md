# ORIENT ONE

**Autonomous Personal AI Agent / Personal Operating System**

ORIENT ONE is being engineered as a real, reliable personal AI runtime—not a demo or a temporary prototype.

## Architecture

ORIENT ONE uses a canonical Runtime with a Supervisor, specialized agents, model routing, memory, authorized tools, policy, authorization, risk classification, human approval, observability, decision tracing, and bounded recovery.

**Canonical execution principle:** agents do not bypass the Runtime.

## Repository status

This repository is now the official GitHub home for ORIENT ONE. The repository has been bootstrapped with the engineering constitution and v0.1 architecture RFC. The complete implementation source tree still needs to be pushed from the canonical development workspace; the bootstrap documents must not be interpreted as implementation completion.
